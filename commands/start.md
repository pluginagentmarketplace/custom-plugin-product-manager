Welcome to the **Product Manager Masterclass** - Comprehensive guide for building world-class products.

This plugin contains **7 specialized agents** that guide you through every stage of product management:

1. **🎯 Strategy & Vision Agent**

2. **🔍 Discovery & Research Agent**

3. **📋 Requirements & Definition Agent**
   - Requirements gathering and specification
   - User story writing (INVEST format)

   - Go-to-market strategy

6. **📈 Analytics & Metrics Agent**
   - KPI definition and dashboarding

7. **👥 Leadership & Stakeholder Agent**
   - Stakeholder management and alignment
   - Executive communication
   - Cross-functional collaboration
   - Product advocacy and change management

## 🚀 Quick Start (5 minutes)

### Phase 1: Strategy & Vision (Weeks 1-2)
Start here if you're launching a new product or entering a new market.
- Analyze market opportunity
- Define product vision
- Design business model
- Create go-to-market strategy

### Phase 2: Discovery & Research (Weeks 3-4)
Understand your customers deeply before building.
- Conduct user interviews
- Create detailed personas
- Map customer journeys
- Validate key assumptions

### Phase 3: Requirements & Definition (Weeks 5-6)
Transform insights into clear requirements.
- Define functional requirements
- Write user stories (30-50+)
- Set acceptance criteria
- Manage scope

### Phase 4: Roadmap & Prioritization (Weeks 7-8)
Plan your execution strategy.
- Apply prioritization frameworks
- Build quarterly roadmap
- Plan releases and sprints
- Allocate resources

### Phase 5: Launch & GTM (Weeks 9-12)
Execute a successful market launch.
- Finalize GTM strategy
- Plan launch campaign
- Enable sales and marketing teams
- Execute launch week

### Phase 6: Analytics & Metrics (Ongoing)
Track success and iterate.
- Define KPIs and North Star
- Build dashboards
- Run A/B tests
- Make data-driven decisions

### Phase 7: Leadership & Alignment (Throughout)
Keep everyone aligned and motivated.
- Manage stakeholders
- Communicate progress
- Resolve conflicts
- Drive organizational change

## 🎓 Best Practices by Phase

### Strategy Phase
✓ Define clear success metrics upfront
✓ Understand your competitive landscape
✓ Get executive alignment early
✓ Document assumptions for validation

### Discovery Phase
✓ Talk to 20+ potential customers
✓ Create detailed personas (3-5)
✓ Map current customer journey
✓ Identify unmet needs and opportunities

### Requirements Phase
✓ Write clear, detailed user stories
✓ Define specific acceptance criteria
✓ Involve engineering early
✓ Document trade-offs

### Roadmap Phase
✓ Use multiple prioritization frameworks
✓ Plan 12-month strategic roadmap
✓ Create detailed 3-month sprints
✓ Communicate roadmap transparently

### Launch Phase
✓ Start planning 12 weeks before
✓ Coordinate cross-functional teams
✓ Create comprehensive launch checklist
✓ Have post-launch support plan

### Analytics Phase
✓ Instrument product from day 1
✓ Track key user behaviors
✓ Build automated dashboards
✓ Run experiments continuously

### Leadership Phase
✓ Over-communicate with stakeholders
✓ Create feedback loops
✓ Make data-driven decisions
✓ Celebrate wins and learnings
