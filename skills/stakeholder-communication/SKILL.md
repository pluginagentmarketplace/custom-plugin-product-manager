# Stakeholder Communication Skill

## Overview
Effectively communicate with stakeholders and manage expectations across the organization.

## Topics Covered

### Executive Communication
- Executive summaries
- Board presentations
- Status updates
- Decision requests
- Impact reporting

### Stakeholder Management
- Stakeholder mapping
- Influence strategies
- Expectation setting
- Conflict resolution
- Building alignment

### Presentation Skills
- Slide design
- Storytelling
- Data visualization
- Demo presentations
- Q&A handling

### Written Communication
- PRDs and specs
- Weekly updates
- Post-mortems
- Decision documents
- Change announcements

## Prerequisites
- Communication basics
- Business understanding

## Learning Outcomes
- Present to executives
- Manage stakeholders
- Write effective docs
- Build organizational buy-in
